# 02 传感器模型

> 传感器的价值不在于“给数据”，而在于“给独立的信息”。理解每个传感器能观什么、不可观什么，才能判断融合是否真的带来约束。

## LiDAR

### 原理与分类

- **测距方式**：脉冲飞行时间（TOF）、相位差、三角测距；
- **扫描方式**：机械旋转（多线）、混合固态（MEMS/转镜）、纯固态（OPA/Flash）；
- **典型输出**：点云 `(x,y,z,intensity,ring,time)`。

### 关键性质

| 性质 | 含义 | 工程影响 |
|---|---|---|
| 角度分辨率 | 相邻两束的角间隔 | 决定远处两点的间距，影响“能不能分辨细杆” |
| 角分辨率 × 距离 | 点间距随距离线性增大 | 远处稀疏 → 配准权重应随距离下降 |
| 扫描周期 | 一帧的持续时间（如 100 ms） | 运动畸变来源（见下） |
| 测距噪声 | 通常与距离相关 | 协方差应距离相关，不要用常数 |
| 无回波 | 玻璃、镜面、黑色吸光面 | 出现“空洞”，未知区不是墙 |

### 运动畸变

一帧点云不是“同一时刻”采集的：扫描周期内机器人已经移动/旋转。高速旋转时，帧首与帧尾的点会差出可观的位移（0.5 m/s × 0.1 s = 5 cm；0.8 rad/s × 0.1 s ≈ 4.6°）。不去畸变会直接降低配准精度，窄道场景尤其明显。

处理方法见第 04 章：按点时间戳插值位姿，把每个点变换到同一参考时刻。

## IMU

### 输出与误差模型

- 输出：角速度 `ω`（rad/s）、比力 `a`（m/s²，含重力）；
- 误差：**零偏**（bias，慢变）、**噪声**（白噪声，高频）、尺度因子、轴间耦合；
- 噪声用两个参数描述：噪声密度（连续谱）与随机游走（零偏的漂移率）。

离散化时要按 `1/√dt` 缩放噪声项，这是“采样率变了结果就变了”的常见原因。

### 能观与不可观

- **可观**：姿态变化率（陀螺）、重力方向（加速度计长期平均）；
- **不可观**：绝对位置、绝对航向（无外部参考时）、速度（需要积分，误差累积）；
- **零偏**：只有在“静止”或“有外部观测”时才可估。

因此 IMU **不能单独提供定位**，只能提供高频的短时运动。

### 静止初始化

上电后静止若干秒，统计陀螺均值 → 零偏初值；加速度均值方向 → 重力方向 → 对齐 roll/pitch。这一步没做好，后面所有积分都带系统偏差。

## 轮式里程计

- 输出：相对位移（通常带非完整约束：差速轮不能横向平移）；
- 优点：短时精度高、成本低、与激光独立；
- 缺点：**打滑**（清洁、湿滑地面尤甚）、轮径误差导致尺度偏差、长时间累积漂移。

工程上的用法：不是“信或不信”，而是**给一个可变的权重**——用角速度一致性和速度上限做门控，打滑时降权而不是直接丢弃（丢弃会导致时间戳不连续）。

## 相机（简述）

- 单目：尺度不可观；
- 双目/RGB-D：尺度可观，但受光照、纹理、深度量程限制；
- 在激光主导的系统里，相机常用于**语义**（门、电梯、充电桩）而不是几何。

## 外参标定

外参是“传感器之间的刚体变换”，有平移和旋转两部分。原则：

1. **一个变换只有一个来源**（TF、URDF 或配置文件，三选一），不要多处定义；
2. 用完整旋转矩阵传递，不要用欧拉角跨模块传递（顺序歧义）；
3. 标定误差要能被观测：标定后在多个位置检查“点云与地图/标定物是否重合”。

时间外参（时间偏移）同样重要：传感器时间戳有几十毫秒偏差时，高速运动会产生系统性位置误差。

## 可观测性直觉表

| 场景 | 可观 | 不可观 |
|---|---|---|
| 长直走廊 | 沿走廊方向位置、横向位置、航向（相对墙） | 走廊方向上的位移（弱约束） |
| 空旷大厅 | 位置（相对稀疏特征） | 位姿整体平移（几乎无约束） |
| 原地旋转 | 航向变化率 | 平移（应严格为 0，可用于校验） |
| 隧道/长通道 | 横向、航向 | 纵向位置 |

这张表的价值：**当你看到位姿沿某个方向持续滑动时，先回想那个方向在当下环境里是否可观**，而不是先怀疑配准器。

## 常见坑（类型化）

| 坑 | 后果 |
|---|---|
| 用常数协方差描述激光观测 | 远处稀疏点被过度信任 |
| 静止初始化不充分 | 陀螺零偏未估，航向持续漂 |
| IMU 噪声未按采样率离散化 | 换传感器/换频率后参数全部失效 |
| 打滑时直接丢弃 odom 样本 | 时间戳不连续，速度估计失真 |
| 外参在多个地方定义且不一致 | 难以复现的“差几度/几十厘米” |
| 时间戳不同源 | 高速时系统性偏移 |

## 自测题

1. 为什么 IMU 单独不能提供绝对位置？它能提供什么？
2. 扫描周期 100 ms、机体以 0.8 rad/s 旋转时，一帧内首尾点相差多少度？这会影响什么？
3. 轮速打滑时，为什么“降权”比“丢弃”更好？
4. 长直走廊里，哪个自由度不可观？如果配准器仍输出该方向的位移，说明什么？
5. 外参为什么要用旋转矩阵而不是欧拉角传递？
