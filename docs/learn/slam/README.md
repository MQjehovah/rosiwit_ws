# SLAM 系统学习文档

面向工程实现的 SLAM 学习材料：从位姿与坐标系讲起，经配准、LIO、后端、回环、重定位、融合、健康度，到评估与工程化。

**目标读者**：能读 C++、接触过 ROS、需要把 SLAM 落到产品上的工程师。

**与其他文档的边界**

| 文档 | 内容 |
|---|---|
| `docs/learn/slam/`（本目录） | 系统性知识：原理、公式、实现要点、常见坑、自测题 |
| `docs/dev/` | 现场复盘、审查结论、事故分析（含具体参数与日志） |
| `docs/superpowers/specs/` | 具体改造的设计文档 |

本目录**不写**任何具体项目的故障与参数，只讲“这类系统为什么这样设计、哪里会坏”。

## 三条学习路径

**算法路径**（想看懂并改算法）
`01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09 → 10`，附录 A 随时查。

**工程路径**（想把系统跑稳、可维护）
`00 → 01 → 03 → 09 → 10 → 11 → 12`，其余按需翻阅。

**测试/评估路径**（想建立回归与验收）
`00 → 11 → 10 → 03 → 04`，重点在“怎么证明它是对的”。

## 阅读约定

- 每章结构固定：**问题 → 原理 → 实现要点 → 常见坑 → 自测题**；
- 图全部使用 Mermaid（见 `docs/dev/docs-conventions.md`）；
- 公式只保留能指导实现的部分，完整推导在附录 A；
- “常见坑”只描述**类型化**的错误（例如“把某一坐标系的位移当世界系用”），不绑定具体项目。
