# 03 前端（一）：帧间配准

> 配准（registration）回答一个问题：**已知两片点云的对应关系，求它们之间的刚体变换**。配准器同时负责“猜对应”和“解位姿”两件事，前者错则后者必错。

## 形式化

给定源点云 `P = {p_i}`、目标点云 `Q = {q_j}`，求 `T ∈ SE(3)`：

```
T* = argmin_T  Σ_i  ρ( ‖ T·p_i − q_{c(i)} ‖ )
```

- `c(i)`：对应关系（通常是最近邻）；
- `ρ(·)`：鲁棒核，抑制外点。

三个要素决定配准器的性格：**如何找对应、如何度量残差、如何处理外点**。

## 三类主流算法

### 1. ICP（点到点）

```
最小化 Σ ‖ (R·p_i + t) − q_i ‖²
```

闭式解：去质心 → 计算协方差矩阵 `H = Σ (p_i−p̄)(q_i−q̄)ᵀ` → SVD 得 R → 解 t。

- 优点：简单、无需法向；
- 缺点：收敛慢、对初值敏感、平坦表面约束弱。

### 2. Point-to-Plane

```
最小化 Σ ( (R·p_i + t − q_i) · n_i )²
```

最小化“点到目标面法向的距离”，把沿面内的误差忽略掉——收敛更快、精度更高。

- 前提：目标点云要有可靠法向；
- 风险：法向估计差（点太少、结构太薄）时反而更差。

### 3. GICP（Generalized ICP）

把每个点建模为局部平面的高斯分布 `N(μ, C)`，最小化分布间距离：

```
d = Σ (q_i − T p_i)ᵀ (C_q + R C_p Rᵀ)⁻¹ (q_i − T p_i)
```

- 优点：兼顾点到点与点到面，性能稳定，是工程最常用的默认选择；
- 代价：需要估协方差，点数太少会退化（实现里要设最小点数保护）。

### 4. NDT（正态分布变换）

把目标空间划成体素，每格用高斯近似，优化“源点在目标分布下的似然”。

- 优点：不依赖逐点最近邻，速度快、对大场景友好；
- 缺点：体素尺寸敏感；分辨率粗时精度下降。

**2D 特化**：把点云投影到平面，只在 `(x, y, yaw)` 上求解，`z/roll/pitch` 取自初值——适合地面机器人、电梯等退化场景。

## 对应点搜索

| 结构 | 适用 | 备注 |
|---|---|---|
| KD-tree | 静态点云 | 建树 O(n log n)，查询 O(log n) |
| ikd-tree | 动态增量点云 | 支持增量插入/删除，LIO 常用 |
| 体素哈希 | 大规模稀疏点云 | 内存友好，精度受体素尺寸限制 |

对应点搜索的三个参数最影响结果：**最大对应距离**（初始误差大时要放宽，收敛后收紧）、**下采样体素**（决定速度）、**法向估计邻域**（决定平面质量）。

## 鲁棒核与外点

| 核 | 特性 |
|---|---|
| Huber | 小残差二次、大残差线性，通用 |
| Cauchy | 对中等外点更宽容 |
| Tukey | 大残差直接归零，激进 |
| GNC（渐进非凸） | 由凸到非凸逐步收紧，外点比例高时更接近全局最优 |

工程经验：**外点主要来自动态物体与地图变化**，鲁棒核只能缓解，真正的解法是动态点剔除（见第 05 章）。

## 收敛判据与协方差

- 收敛：位姿增量小于阈值、或残差下降率小于阈值、或达到最大迭代；
- **协方差**：`Cov ≈ (Jᵀ W J)⁻¹`（J 为残差对位姿的雅可比）。它有两层用途：
  1. 作为融合时的观测噪声 R（第 09 章）；
  2. 作为退化检测的依据（下节）。

**协方差的可靠性依赖点数与几何**：点数少时协方差被低估，必须设下限，否则融合会过度信任一次弱观测。

## 退化与可观测性

对 `H = Jᵀ W J` 做特征分解：

```
H = V Λ Vᵀ
```

- 最大特征值方向：约束最强；
- **最小特征值方向：最弱，甚至不可观**（长走廊的纵向、空旷大厅的平移）。

处理方式：

1. **部分更新**：弱观测方向的修正量按比例衰减（甚至冻结），保留先验；
2. **降级**：把该帧标记为“不可信”，交给健康机制；
3. **判定条件**：`λ_min < ratio · λ_max` 或条件数超阈值。

> 注意：很多系统“声称”做了退化处理，实际是空实现或默认关闭。实现时要能验证——人为构造退化场景（长走廊），看输出是否真的沿该方向冻结。

## 实现要点清单

1. **初值决定一切**：配准是局部优化，初值差 > 对应距离上限就必失败；
2. **降采样与精度**：0.2~0.3 m 体素是常见折中；定位阶段可更细；
3. **对应距离递减**：初始放宽、迭代中收紧，兼顾捕获范围与精度；
4. **最小点数保护**：点数过少直接判失败，不要让它跑出“看似收敛”的错解；
5. **协方差下限**：防止弱观测被当成高置信度；
6. **退化检测**：至少记录 `λ_min/λ_max`，便于事后分析。

## 常见坑（类型化）

| 坑 | 表现 |
|---|---|
| 用上一帧位姿直接当初值而不做运动预测 | 高速/急转时失配 |
| 对应距离设太大 | 收敛到错误局部极小（“滑到隔壁墙”） |
| 只看法向残差、不看覆盖率 | 少量点也能“完美拟合” |
| 协方差没有下限 | 融合时弱观测被过度信任 |
| 退化方向不处理 | 长走廊沿墙滑动，匹配分数仍很高 |
| 下采样后点数太少 | 数值不稳定，甚至崩溃 |

## 自测题

1. 点到点与点到面在“沿墙滑动”场景下，哪个更容易滑？为什么？
2. 为什么最大对应距离不能一开始就设得很小？
3. 配准协方差矩阵的对角线元素变大，意味着什么？融合时应该怎样用它？
4. 长走廊里 `λ_min` 很小，说明哪个方向不可观？应该如何处理该方向的修正？
5. 一个配准器每次都能“收敛”，是否说明结果可信？还需要什么额外信息？
