# 附录 A 数学基础

## A.1 李群与李代数（够用版）

### SO(3) 与 so(3)

旋转矩阵 `R ∈ SO(3)`。其李代数 `φ ∈ so(3)` 是三维向量（轴角表示），指数映射（Rodrigues）：

```
Exp(φ) = I + sin(θ)/θ · φ^ + (1−cos θ)/θ² · (φ^)²
θ = ‖φ‖,  φ^ = 反对称矩阵
```

对数映射：`φ = Log(R)`，方向为旋转轴，模长为转角。

### SE(3) 与 se(3)

```
Exp(ξ),  ξ = [ρ; φ] ∈ R⁶
```

小量近似（最常用）：

```
Exp(δ) ≈ I + δ^     （δ 足够小时）
```

### 右雅可比（近似）

迭代优化里常用其逆或近似：

```
J_r⁻¹(φ) ≈ I + ½ φ^
```

只有在大角度时才需要完整形式；工程实现里 99% 用的是这个近似。

### 为什么用李代数

1. 旋转只有 3 个自由度，李代数无冗余、无约束；
2. 可以正常做加减与求导（`R ⊞ δ = R·Exp(δ)`）；
3. 残差与雅可比在小量下线性化良好。

## A.2 最小二乘与迭代求解

### 高斯-牛顿（GN）

```
r(x),  J = ∂r/∂x
解 (JᵀJ) Δx = −Jᵀ r
x ← x ⊞ Δx
```

- 收敛快（二阶）；
- 残差大或初值差时可能发散。

### Levenberg-Marquardt（LM）

```
(JᵀJ + λI) Δx = −Jᵀ r
```

- `λ` 大 → 退化为梯度下降（稳）；
- `λ` 小 → 接近 GN（快）；
- 根据残差是否下降自适应调整 `λ`。

### 鲁棒核的加权形式

```
min Σ ρ(‖r_i‖²)   ⇔   min Σ w_i ‖r_i‖²,  w_i = ρ'(‖r_i‖²)
```

即：把鲁棒核转成“逐项权重”，仍用加权最小二乘求解（IRLS）。

## A.3 卡尔曼滤波

### 线性 KF

状态 `x`，协方差 `P`。

**预测**：

```
x⁻ = F x + B u
P⁻ = F P Fᵀ + Q
```

**更新**：

```
S  = H P⁻ Hᵀ + R
K  = P⁻ Hᵀ S⁻¹
x  = x⁻ + K (z − H x⁻)
P  = (I − K H) P⁻
```

`K` 的直觉：`P` 大（不确定）→ 更信观测；`R` 大（观测差）→ 更信预测。

### 误差状态 KF（ESKF）

名义状态 `x` 与误差状态 `δx` 分离：

```
预测：δx⁻ = F δx + 噪声,   P⁻ = F P Fᵀ + Q
更新：δx = K (z − h(x)),   x ← x ⊞ δx
重置：δx ← 0,  P ← G P Gᵀ   （G 为重置雅可比）
```

好处：误差量始终是小量，线性化误差小；旋转不会因加减而失去正交性。

### 马氏距离与 χ² 检验

```
d² = νᵀ S⁻¹ ν,  ν = z − h(x),  S = H P Hᵀ + R
```

`d²` 服从卡方分布（自由度 = 观测维度）。超过阈值（如 6 维 99% ≈ 16.81）判为离群。

### NEES

```
NEES = eᵀ P⁻¹ e,  e = x − x_true
```

衡量“协方差是否诚实”。NEES 长期远大于理论值 → 过度自信（P 偏小）；远小于 → 过度保守。

## A.4 信息矩阵与协方差

```
Ω = Cov⁻¹
```

- 用信息矩阵写优化更自然（加权最小二乘）；
- 用协方差写滤波更自然；
- 两者互为逆，但**数值上不要真的求逆**——用 Cholesky 求解即可。

## A.5 常用近似与陷阱

| 近似 | 适用 | 陷阱 |
|---|---|---|
| `Exp(δ) ≈ I + δ^` | δ 很小（< 几度） | 大角度误差不可忽略 |
| `J_r⁻¹ ≈ I + ½φ^` | 同上 | 大旋转时精度下降 |
| 协方差对角化 | 观测弱相关 | 强相关时低估不确定度 |
| 常数 R/Q | 快速原型 | 换场景后行为完全改变 |
