# 01 位姿、坐标系与变换

> 这一章是全书的地基。绝大多数“位姿跳变”“差 90°”“越走越偏”的问题，根都在这里。

## 位姿是什么

位姿（pose）由两部分组成：**位置**（3 维平移）与**姿态**（3 维旋转）。刚体变换属于特殊欧氏群 SE(3)：

```
T = [ R  t ]      R ∈ SO(3), t ∈ R³
    [ 0  1 ]
```

点变换：`p_world = R · p_body + t`，写成齐次形式 `[p_world; 1] = T · [p_body; 1]`。

**变换的复合顺序**：`T_ac = T_ab · T_bc` 表示“先把点从 c 变到 b，再变到 a”。矩阵乘法不可交换，顺序错了就是“差 90°”这类问题的常见来源。

## 旋转的四种表示与各自的坑

| 表示 | 维度 | 优点 | 坑 |
|---|---|---|---|
| 旋转矩阵 R | 9（约束后 3） | 无奇异、可直接复合 | 正交性误差会累积，需周期重正交化 |
| 欧拉角 (roll,pitch,yaw) | 3 | 直观 | **万向节死锁**；顺序约定极多（rpy/zyx/xyz） |
| 四元数 q | 4（模 1） | 紧凑、插值好 | 未归一化会导致变换不是刚体；符号双覆盖 |
| 轴角 (axis,angle) | 4 | 适合表达“绕某轴转多少” | 小角度时数值不稳定 |

**实践建议**：内部计算用旋转矩阵或四元数，只有“人机界面/日志”才用欧拉角；任何跨模块传递姿态都明确写出约定（例如“ZYX 顺序，单位度”）。

### 从旋转矩阵取 yaw 的陷阱

常见写法 `yaw = atan2(R(1,0), R(0,0))` 只在**旋转是纯偏航**时成立。如果传感器是倾斜安装（例如雷达俯装 40°），该式提取出的角度会把俯仰混进航向。正确做法是明确“我要的是哪个坐标系的哪个轴在水平面的投影”，并先把倾斜外参补上。

## 左乘与右乘：扰动的两种写法

优化和滤波里经常需要“在位姿上加一个小扰动”，两种约定不能混：

```
右乘（体体系扰动）：T' = T · Exp(δ)      δ 表达在 body 坐标系
左乘（世界系扰动）：T' = Exp(δ) · T      δ 表达在 world 坐标系
```

对应的雅可比矩阵不同。**一个工程里必须统一**，否则“同样的公式换个模块就不收敛”，且极难排查。

## 坐标系与 TF 链

典型机器人坐标链：

```mermaid
flowchart LR
  m["map<br/>全局地图系（绝对）"] -- 定位修正 --> o["odom<br/>里程计系（连续、会漂）"]
  o -- 轮速/里程计 --> bf["base_footprint<br/>地面投影"]
  bf -- 静态 --> bl["base_link<br/>车体"]
  bl -- 静态（含安装角） --> s["sensor<br/>雷达/相机"]
```

三条规则：

1. **map→odom 是“修正量”，不是常量**。它随每次重定位变化；把它的数值写死进代码，重定位后就全错。
2. **odom 系与 map 系一般存在固定旋转差**。用 odom 系位移直接做世界系运算，等于把结果整体旋转一个未知角度。
3. **“世界系”必须指明**：地图系、里程计系、重力对齐系是不同的东西。

### 判断写法是否正确的一个小技巧

任何“由位移求速度”的公式，先问一句：**这个位移表达在哪个系？用在哪个系？** 如果两者不一致，必须显式乘一个旋转。例：

```
体系速度 = R(θ_frame)ᵀ · Δp_frame / dt
```

用它自检：车直行时，算出的速度应主要落在 x 轴上；如果主要落在 y 轴，就是差了一个 90° 量级的旋转。

## 时间与同步

- 每个量都带时间戳；跨传感器融合前必须统一时钟域（同一 `ros::Time` / 同一硬件时钟）；
- 变换要按**时间查询**，而不是“取最新”；
- 点云内部每个点也有时间（扫描期间机器人一直在动），见第 04 章去畸变。

**常见坑**：把“最新可用变换”用于一帧几百毫秒前的数据，在 0.5 m/s、0.8 rad/s 的工况下就会产生厘米到十厘米级错位——足以让窄道判断失效。

## 常见坑（类型化）

| 坑 | 表现 | 定位方法 |
|---|---|---|
| 欧拉角顺序不一致 | 姿态差几十度 | 打印同一姿态的两种约定对比 |
| 左乘/右乘混用 | 优化不收敛或收敛到错解 | 检查雅可比推导的扰动定义 |
| 把 odom 位移当世界位移 | 直行被判为横移、越走越偏 | 用“直行应落在 x 轴”自检 |
| 用倾斜帧的 `atan2` 取 yaw | 航向系统性偏 10°~40° | 与陀螺积分航向比对 |
| 用最新 TF 配旧数据 | 高速时位置抖动 | 比较时间戳差与速度乘积 |
| 四元数未归一化 | 位姿缓慢“缩放” | 定期检查 `‖q‖-1` |
