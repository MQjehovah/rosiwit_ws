# 地图质量排查 (2026-11-02) —— 用户反馈"costmap 上贴墙, 实车还离得远"
# ============================================================================

## 结论: 两个独立问题叠加

### 1) 视觉上"贴墙" = 内切/膨胀层盖住 footprint (已修)

`/global_costmap` 在车体 1.8m 窗口的代价构成:

| 值 | 含义 | 改前 (infl 0.62 / r 0.39) | 改后 (0.32 / 0.262) |
|---|---|---|---|
| 0 | free | 259 格 | **823 格** |
| 99 | 内切/膨胀 (kCostInscribed) | 512 格 | 339 格 |
| 100 | 真障碍 | 79 格 | 79 格 |

footprint 内 247 格: 改前 `99=135, 100=16, 0=24` → 改后 `0=117, 99=100, 100=16`。

`inflation_radius 0.62` 意味着"距障碍 0.62m 以内"都是膨胀区, 而车体半宽只有 0.34,
所以 footprint 整块被 99 覆盖 → RViz 里看就是"贴着墙"。0.62 还会让 <1.24m 的通道
整段变成内切代价, 窄门基本规划不出来 → 已降到 0.32 (车体+6cm), robot_radius 改真内切 0.262。

### 2) 静态地图本身偏胖 (未修, 属建图子系统)

**判据: 激光射线自由性** —— 激光从车体打到障碍, 沿途必须是 free。

```
/map 691x449 res=0.05 origin=(-25.13,-12.94)
值分布: free 55.5% / occupied(>=65) 8.1% / unknown 36.4%
车体位姿格 = 0 (free)          <- 原始地图里车不在墙里

射线沿途(0.4/0.6/0.8 处)被地图判为 occ/unknown 的比例, 按距离分桶:
  <=1.0m : 41.9%
  1-2m   : 33.5%
  2-3m   : 46.4%
```

近处也 42% → 不是远处位姿误差, 是**地图内容偏胖**。
同时"扫描命中点 → 最近地图障碍"中位数 0.023m (p90 0.046) → **地图与实景对齐**,
所以不是定位/坐标系问题, 是地图把"看得穿的地方"写成了障碍。

可能来源 (2026-11-02 配置收敛后修正):

> 之前把原因归到 legacy `slam_conf.json` 的 `use_3d_z_min: 0.0` / `use_3d_z_max: 10`。
> **该结论已作废**: 这两个键在核心 `rosiwit_slam` 里没有任何读取点, 且 `conf/slam_conf.json`
> 已删除。真正决定 2D 栅格高度带的是 `config/default.yaml`:
>
> ```yaml
> mapping.grid:
>   min_height: 0.35   # 地面以上障碍最低高度
>   max_height: 2.0    # 地面以上障碍最高高度
>   dilate_radius: 1   # = 5cm/侧
>   close_radius: 1
>   occupied_thresh: 1
> ```

所以在 0.35–2.0m 带内的家具/人体/杂波都会被写进地图 (建图时现场有人的话尤其明显);
`dilate_radius 1` 再让每个障碍格向外长 5cm (0.78m 门洞两侧各损失 5cm → 自由宽度 0.68m,
**小于验收要求的 0.78m**)。另外上面的探针把 `unknown` 和 `occupied` 合并计数了,
还需分离复测才能定"真的胖"还是"没建到"。

### 影响

- 规划器按地图走 → 偏保守/绕行; 窄门处地图的自由宽度会比物理宽度小,
  可能直接规划不出来 → **会掩盖或伪造"过不去"的结论**。
- 安全层按雷达 → 不受地图影响 (该停还是停)。

### 建议的修法 (按代价从低到高)

1. **收窄地图高度带**: 调 `mapping.grid.min_height / max_height` (与 2D 雷达的观测面一致,
   例如 0.15–1.2m), 并把 `dilate_radius` 降到 0 或改用非对称余量, 重录/重建地图,
   用 `scripts/sim/map_quality_probe.py` 复测 (目标 <=5%)。
2. **地图后处理**: 形态学开运算去散点 + 只用 `min_hits>=2` 的格子; 或"用当前激光
   证明为 free 的位置擦掉障碍"(slam 里有 `repair_map_grid` 类似机制)。
3. 验收前必须在**真实门洞处**量地图的自由宽度 (>= 车宽+10cm), 否则门洞结论不可信。

## 工具

  - 射线自由性 + 按距离分桶
