## 结论: 视觉"贴墙"已修; 地图经复测**不是大面积偏胖**, 但门洞自由宽度仍需实测

### 1) 视觉上"贴墙" = 内切/膨胀层盖住 footprint (已修)

`/global_costmap` 在车体 1.8m 窗口的代价构成:

| 值 | 含义 | 改前 (infl 0.62 / r 0.39) | 改后 (0.32 / 0.262) |
|---|---|---|---|
| 0 | free | 259 格 | **823 格** |
| 99 | 内切/膨胀 (kCostInscribed) | 512 格 | 339 格 |
| 100 | 真障碍 | 79 格 | 79 格 |

footprint 内 247 格: 改前 `99=135, 100=16, 0=24` → 改后 `0=117, 99=100, 100=16`。

`inflation_radius 0.62` 意味着"距障碍 0.62m 以内"都是膨胀区, 而车体半宽只有 0.34,
所以 footprint 整块被 99 覆盖 → RViz 里看就是"贴着墙"。0.62 还会让 <1.24m 的通道
整段变成内切代价, 窄门基本规划不出来 → 已降到 0.32 (车体+6cm), robot_radius 改真内切 0.262。

### 2) 静态地图: **不是大面积偏胖**(前一版结论已修正)

**判据: 激光射线自由性** —— 激光从车体打到障碍, 沿途必须是 free。
**采样必须用固定绝对距离**, 且要求命中点再远 0.2m; 否则 `0.4/0.6/0.8 × range`
会落进"命中面 + 膨胀"里, 把正常墙算成地图偏胖 (前一版就是这样算出 42% 的)。

```text
/map 691x449 res=0.05 origin=(-25.13,-12.94)
值分布: free 55.5% / occupied(>=65) 8.1% / unknown 36.4%
车体位姿格 = 0 (free)          <- 原始地图里车不在墙里

固定距离采样 (range > d + 0.2), 只算地图内:
total 2700: free 82.5% / occupied 16.5% / unknown 1.0%

  dist       n   occupied   unknown
  0.3m     767      30.5%      0.0%
  0.5m     590       6.9%      0.0%
  0.8m     590       0.0%      0.0%   <- 这一圈 100% free
  1.2m     422      16.6%      0.0%
  1.8m     331      30.5%      7.9%
```

车体周围 ASCII 里 footprint 左侧紧贴一堵 `#` (充电桩/墙), 所以 0.3m 的 30.5%
是**真正的近处结构**, 不是地图胖; 0.8m 整圈 0% occupied 说明**地图没有被全局膨胀**。
1.2/1.8m 的 occupied 主要是低矮家具/桌椅腿: 地图高度带是 0.35–2.0m,
而安全层的 2D 雷达只有 7.5cm 高, 从桌子下面穿过去 —— 两边对"障碍"的定义不同。

同时"扫描命中点 → 最近地图障碍"中位数 0.023m (p90 0.046) → **地图与实景对齐**,
不是定位/坐标系问题。

#### 仍然成立的两个隐患

1. **`dilate_radius: 1` = 每侧 5cm**: 对 0.78m 门洞意味着**静态地图里自由宽度可能只剩
   0.68m**(< 验收要求的 0.78m)。**必须在真实门洞处量地图自由宽度**, 否则门洞结论不作数。
2. **`mapping.grid.min_height: 0.35 / max_height: 2.0`** 会把 0.35–2.0m 的家具/人体/杂波
   写进地图 (建图时现场有人的话尤其明显)。与 2D 雷达的观测面不一致, 但这是设计取舍,
   不是 bug。

> 已作废的旧结论: 曾把原因归到 legacy `slam_conf.json` 的 `use_3d_z_min: 0.0` /
> `use_3d_z_max: 10`。这两个键在核心 `rosiwit_slam` 里**没有任何读取点**, 且
> `conf/slam_conf.json` 已删除。真正决定 2D 栅格的是 `config/default.yaml` 的
> `mapping.grid.*`。

### 影响

- 规划器按地图走 → 地图里比物理世界多出的障碍 (家具/膨胀) 会让窄通道更窄;
  但**当前地图在 0.8m 环上完全 free, 没有"整片胀掉"**。
- 安全层按雷达 → 不受地图影响 (该停还是停)。

### 建议的修法 (按代价从低到高)

1. **先量真实门洞**: 在门洞处用 `map_quality_probe.py` 的 ASCII + 自由宽度检查,
   确认 `自由宽度 >= 676 + 100 = 776mm`。若不足, 优先降 `dilate_radius` (1 → 0)。
2. **重建地图时**: 把 `mapping.grid.min_height` 提到 0.5 左右 (滤掉桌椅腿/地面杂波),
   建图现场清人; 重建后用 `map_quality_probe.py` 复测 (occupied 目标 <=5%)。
3. **地图后处理**: 形态学开运算去散点 + `min_hits>=2`; 或用当前激光"证明为 free"
   的位置擦掉障碍 (`repair_map_grid` / `map_cleanup`)。
